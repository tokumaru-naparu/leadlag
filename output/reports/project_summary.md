## 🔴 第1段階：初期問題の発見と解決

### 問題1：ETFテスト利回りの計算誤差

**背景**：
- Phase 1（ETF版）でテスト利回りが計算されていた
- Phase 2（個別株版）に移行する際、詳細な銘柄別分解が必要になった

**初期アプローチの問題**：
```
ロング銘柄3つのOCリターン合計 ÷ 3 = 銘柄1のリターン
ショート銘柄3つのOCリターン合計 ÷ 3 = 銘柄1のショート損益
```

❌ **問題点**：
- 実際には各日で各銘柄のOC（Open-to-Close）リターンは異なる
- 3等分すると、個別銘柄の「実際のロング/ショート日数」が失われる
- 銘柄ごとの正確な損益追跡ができない

**ユーザーからの指摘**：
> 「簡略化しないで各銘柄の実OCリターンを使え」
> 「複利vs単純合計の乖離を正しく説明しろ」

### 2-2. 主要な技術課題と解決

#### 課題1：日付マッチング失敗
**症状**：yfinanceから取得したDataFrameで日付インデックスが正しく機能しない

**解決**：
```python
# 日付を明示的な列に変換
df['date'] = pd.to_datetime(df.index)
df = df.reset_index(drop=True)
# その後、正確な日付マッチングが可能に
```

#### 課題2：Suntory（2587）データ不足
**症状**：2587（食品セクター代表）が2013年7月からのみデータがある
- 2010-2013年の食品セクターの利益が計上されない
- 全体との乖離：6.54ポイント

**解決**：
```python
# 各銘柄について日付範囲チェック
if ticker_date not in stock_df.index:
    continue  # その日のデータがなければスキップ
```

**影響**：
- 2010-2013年の食品セクター利益が一部欠落
- これが全銘柄合計16.21倍とPhase 1(ETF版)との微小な乖離の主因

#### 課題3：複利vs単純合計
**ユーザー質問**：
> 「銘柄別合計（9.67倍）がstrategy_return（16.21倍）と異なるのはなぜ？」

**根本原因**：
- `strategy_return`：複利で計算（毎日の%リターン）
- `銘柄別合計`：単純加算（各銘柄の%を合計）

**解決と説明**：
- 平均日次%の計算は「累積リターン ÷ 総日数」で正確
- この方法では複利の効果を保持する必要がない
- 各銘柄ごとに「平均日次%」を計算することが正しい

## 🟢 第3段階：銘柄別利益分析の実装

### 3-1. 分析スクリプト開発

**Script: `analyze_sector_profit_by_ticker.py`**

**アルゴリズム**：
```
for each day in trades_v2.csv:
    if sector in long_1/2/3:
        ticker_return += stock[date].OC%  # Open-to-Close%
    if sector in short_1/2/3:
        ticker_return -= stock[date].OC%

銘柄別_平均日次% = (累積OC% / 取引日数) × 100
```

**出力**：`ticker_profit_analysis.csv`

### 3-2. 主要発見

**最高パフォーマー（全期間）**：
1. **8053（商社）**：+0.25% / 日 → +36.02%累積
2. **8354（銀行）**：+0.18% / 日 → +24.88%累積
3. **4536（医薬品）**：+0.20% / 日 → +28.97%累積

## 🔵 第4段階：年別銘柄ランキング分析

### 4-1. 年別分析スクリプト開発

**Script: `analyze_yearly_ticker_performance.py`**

**実装ロジック**：
```
for each year (2010-2026):
    for each ticker:
        long_days = count(セクター in long_1/2/3)
        short_days = count(セクター in short_1/2/3)
        total_return = Σ(long日のOC%) - Σ(short日のOC%)
        平均日次% = total_return / (long_days + short_days) × 100

    年間ランキングを平均日次%でソート
```

**出力**：
- `yearly_ticker_ranking.txt`（見やすい表形式）
- `yearly_ticker_ranking.csv`（データ用）

## 💡 主要な技術的洞察

### 1. PCA SUB（部分空間正則化PCA）の有効性
- パラメータ：λ=0.9, K=3, L=60日
- 米国ETFの3成分でアルファを抽出
- 日本個別株との相関を活用

### 2. IC（情報係数）による銘柄選定
- Phase 1：165の候補銘柄を評価
- 最高IC銘柄を17個選定
- Adoption A/B/C/Dで層別

### 3. リード・ラグ関係の実証
- US Close → JP Open-to-Close という非効率性を利用
- 日本が米国シグナルに対して「後ろ遅れ」している
- この時差を売買で獲得

### 4. 複利効果の重要性
- 単純加算（9.67倍）vs複利（16.21倍）
- 16年間のコンパウンディング効果 = 1.68倍
- 日次リターンの安定性が鍵

## 🎯 ビジネス的インサイト

### 1. セクターローテーション戦略の実証
- 同じ銘柄が常に勝つわけではない
- 年ごとに異なるセクターが主導権を握る
